#  Приложение для анализа банковских операций

Приложение на Python для обработки, анализа и фильтрации банковских транзакций из Excel-файлов (`operations.xlsx`). Проект формирует JSON-данные для веб-страниц, предоставляет аналитические сервисы и генерирует финансовые отчёты.

---

##  Технологический стек

* **Python:** 3.13
* **Управление зависимостями:** Poetry
* **Анализ данных:** Pandas, OpenPyXL
* **Работа с сетевыми API:** Requests, Python-Dotenv
* **Тестирование:** Pytest, Pytest-Cov (покрытие кода **97%**)
* **Качество кода:** Flake8, Black, Isort, Mypy

---


️ Установка и настройка
Клонируйте репозиторий:

````

git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd Coursework
````
Установите зависимости через Poetry:

``````
poetry install
``````

Настройте переменные окружения:
Создайте файл .env на основе .env.example:

cp .env.example .env
Укажите в .env ваши ключи API для APILayer и Financial Modeling Prep:

````env

API_KEY=your_apilayer_key_here
STOCKS_API=your_fmp_key_here
````
Настройки пользователя (user_settings.json):

``````

{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}
``````
 Функциональность модулей

1. Слой данных и API (src/utils.py)
excel_reader: Считывает файл operations.xlsx в список словарей с очисткой от NaN.
load_user_settings: Загружает настройки пользовательских валют и акций из JSON.
get_currency_rates: Запрашивает актуальные курсы валют к рублю через APILayer Exchange Rates API.
get_stock_prices: Запрашивает текущие котировки акций через Financial Modeling Prep API.
2. Веб-страницы (src/views.py)
main_page: Генерирует JSON-ответ для страницы «Главная»:
Динамическое приветствие по времени суток («Доброе утро», «Добрый день» и т.д.).
Расходы и кешбэк по каждой карте за текущий месяц.
Топ-5 крупнейших транзакций.
Актуальные курсы валют и цены акций.
3. Сервисы (src/services.py)
investment_bank: Расчёт накоплений в «Инвесткопилку» за указанный месяц (YYYY-MM) с шагом округления трат (10, 50 или 100 ₽).
4. Отчёты (src/reports.py)
@report_to_file: Декоратор для автоматической записи результатов функций-отчётов в JSON-файл (поддерживает работу с параметром имени файла и без него).
spending_by_category: Возвращает pd.DataFrame с операциями по указанной категории за последние 3 месяца от переданной даты.
 Тестирование и качество кода
В проекте написано 17 модульных тестов с использованием моков (unittest.mock.patch) для изоляции сетевых запросов и файловой системы.

Запуск всех тестов:

````````

poetry run pytest
````````
Генерация отчёта о покрытии:

````````

poetry run pytest --cov=src --cov-report=term-missing
````````
(Текущее покрытие кода тестами: 97%)

Проверка линтерами и статической типизацией:

````
poetry run flake8 .
poetry run black --check .
poetry run isort --check-only .
poetry run mypy .
````
